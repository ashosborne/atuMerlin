## Summary

Exact (source): options 80–82 sit in the `:menugrp.Utilities` block of `SAMMNU` between the parameter / country maintenance (20, 21) and the IFS / log viewers (83, 84); their texts are "Reset LASTORDNO", "Reset Order dates to current", "Reset Summary Fields". Exact: `ORD900` and `ORD901` are the only two `QRPGLESRC` programs besides `ORD700` and `PRO203` whose `%TEXT` header is blank — every interactive program says what it is ("Create new order", "Work with Customer Orders", …); `ART801`'s is blank too. Exact: `LASTORDNO.DTAARA` is ARCAD-generated (`Source generated by ARCAD Software … 2022-05-17`) with seed `60719`; `iproj.json` describes the repository as `AdrianAtArcad`. Exact: what `ORD901` does — move every date so the newest order is today, invent close dates for old deliveries, then repair derived fields — is what one does to a **demonstration data set** that has aged, not to a ledger. Inferred: the three utilities exist to refresh the sample between demos. No comment, text, or document in the tree says so; the Phase A recommendation ("if confirmed, defer the whole slice from conversion scope") is therefore still a recommendation. The ORD Architecture pack already lists `ORD900` / `ORD901` / `ART801` as *not converted* (`modern/README.md:405`, cited read-only) — consistent with the reading, not proof of it.

## Behaviour as implemented

1. **Menu placement and wording (source).** Group "Utilities"; texts "Reset LASTORDNO" / "Reset Order dates to current" / "Reset Summary Fields"; no help (`help=nohelp.`); no confirmation; every signed-on user sees them (`menu-cmd-shell-c01`). — `SAMMNU.MENU:134-154`
2. **Metadata (source).** `%TEXT` blank on `ORD900`, `ORD901`, `ART801` (also on `ORD700`, `PRO203`); every other `QRPGLESRC` member has a descriptive text. — survey of line 2 of all 37 `QRPGLESRC` members; `ATU_SRC/QSQLSRC/ART801.SQLPRC:2`
3. **Data-area provenance (source).** `LASTORDNO.DTAARA` header: `Source generated by ARCAD Software`, `Using Direct Object FGRMON_DTA/LASTORDNO`, `Time : 2022-05-17`; `VALUE(60719)` — a snapshot of a live value, not a design constant. — `ATU_SRC/QDTASRC/LASTORDNO.DTAARA:4-8`
4. **What the code does (source, `c01`–`c05`).** Reset a counter to match the data; move all dates so the sample looks current; synthesise closes; repair derived columns. None of it takes a parameter, a date range or a customer.
5. **Reading (inferred).** Steps 1–4 together describe demo-refresh tooling. The alternative reading — a real month-end / data-fix batch — is not excluded by anything in the tree, only made unlikely by the absence of parameters, scheduling (`c08`), logging (`ORD901` never calls `AddLogEntry`, unlike `ORD700`'s delete branch) and any business wording.
